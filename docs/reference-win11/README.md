# Références Windows 11

Images **de comparaison visuelle uniquement** (jamais copiées dans le thème, jamais distribuées : `scripts/package.sh` n'embarque pas `docs/`). Droits : voir `ATTRIBUTION.md`, section « Reference images ».

Deux jeux :

| Jeu | Contenu | Citées dans les docs comme |
|-----|---------|----------------------------|
| `NN.jpeg` (ce dossier) | 24 captures fournies par Patrick (2026-11-13), numérotées par ordre alphabétique d'origine | `[NN]` (ex. `[14]`) |
| `originaux/` | 34 images fournies par Patrick (2026-11-20), 4 sous-dossiers par provenance, noms d'origine conservés | `[Znn]` (ex. `[Z27]`), table ci-dessous |

Règle (méthode §5) : ces images servent à juger **le style** (proportions, rayons, espacements, hiérarchie). Elles ne sont pas à l'échelle de nos captures CI (1920×1080 ou 1024×768) : pour comparer des tailles, mesurer un élément connu (ex. ligne de menu 32 px) puis ramener à l'échelle, ne pas superposer.
